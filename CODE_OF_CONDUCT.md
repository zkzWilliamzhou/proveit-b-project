# Code of conduct

Be direct about technical disagreements and civil about people. Critique the
code, the claim or the evidence, not the contributor.

Harassment, personal attacks, discriminatory language and publishing someone
else's private information are not acceptable. Report an incident to the
maintainers through a private channel.

Maintainers may remove comments, issues or pull requests that violate this
policy, and will explain the removal when it is safe to do so.
